# NLR Firmware

NLR est un firmware pour fusée conçu spécialement pour un contrôleur de vol de type T-MOTOR F7, équipé d'une puce STM32F722RET6.

## Objectif

Son objectif est de gérer la fusée pendant tout le vol.
Pour l'instant, la v1 se limite à envoyer des données à la station au sol et à éjecter le parachute. À l'avenir, on pourrait envisager un contrôle de direction sur des fusées plus puissantes.

## Matériel cible

- Contrôleur de vol de type T-MOTOR F7
- MCU STM32F722RET6
- Communication radio / télémétrie vers la station au sol

## Fonctionnalités actuelles

- Acquisition et transmission des données de vol
- Gestion de l'éjection du parachute
- Base de développement pour des fonctionnalités supplémentaires
